🚀 Deploy HTX Bình Mỹ lên Internet

Hướng dẫn từng bước — tổng cộng ~5 phút

📌 Tóm tắt: Code đã có sẵn trên GitHub (mọi config đã chuẩn bị xong). Bạn chỉ cần làm 2 thao tác click là xong.
1

Bật GitHub Pages (30 giây)

Mở trang Settings → Pages của repo, đổi Source thành GitHub Actions:

⚙️ Mở trang Pages Settings

Cách làm:

  1. Bấm vào nút "Mở trang Pages Settings" ở trên
  2. Đăng nhập GitHub nếu chưa (tài khoản baookhangggg)
  3. Tìm dòng "Source" → bấm dropdown → chọn "GitHub Actions"
  4. Đợi 1-2 phút, tab Actions sẽ chạy workflow deploy
✅ Khi xong, website sẽ live tại: https://baookhangggg.github.io/binhmy/
2

Deploy Backend lên Render (2 phút)

Render sẽ tự động đọc file render.yaml trong repo và tạo service với mọi thứ cấu hình sẵn:

🚀 Deploy lên Render (1 click)

Cách làm:

  1. Bấm nút "Deploy lên Render" ở trên
  2. Đăng ký/đăng nhập Render bằng GitHub (1 lần duy nhất)
  3. Render sẽ hiển thị blueprint từ render.yaml — bấm "Apply"
  4. Đợi 3-5 phút để build & deploy
  5. Khi xong, copy URL service (ví dụ: https://htx-binh-my-api.onrender.com)
⚠️ Quan trọng: Sau khi deploy, copy URL chính xác từ Render dashboard.
3

Cập nhật URL cho Frontend (30 giây)

Sửa 1 dòng trong file public/js/config.js để trỏ tới backend Render vừa tạo:

✏️ Sửa config.js

Sửa dòng đầu tiên thành URL Render của bạn:

const API_BASE = 'https://htx-binh-my-api.onrender.com/api';

Bấm "Commit changes" → xong!

✓

Hoàn thành — Kiểm tra

Mở website và kiểm tra mọi thứ hoạt động:

🌐 Website chính: https://baookhangggg.github.io/binhmy/

🔌 API Health: https://htx-binh-my-api.onrender.com/api/health
